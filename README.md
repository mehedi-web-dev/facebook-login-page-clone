# 🔵 Facebook Login Page Clone

A responsive Facebook login page clone built with HTML5 and CSS3, inspired by the original Facebook login interface.

---

## 📊 Project Overview

This project is a front-end clone of the Facebook login page, created to practice layout design, form styling, responsive web design, and recreating a real-world website interface using HTML and CSS.

The page includes a promotional section, login form, account creation button, Meta branding, and footer navigation links.

## ✨ Key Features

### 1. 🔵 Facebook-Style Login Interface

- Facebook logo and promotional content
- Login form with email/mobile number and password fields
- Login button
- Forgot password link
- Create new account button
- Meta branding

### 2. 🎨 Promotional Section

- Large promotional headline
- Facebook-themed visual content
- Social media style graphics and elements

### 3. 📱 Responsive Design

- Responsive layout for desktop, tablet, and mobile devices
- Flexible two-column layout
- Mobile-friendly login section
- Proper spacing and sizing across different screen sizes

### 4. 🦶 Footer

- Language selection links
- Facebook-related navigation links
- Privacy and policy links
- Additional Meta-related links

## 📦 Dependencies

No JavaScript framework or backend dependency is used.

The project is built using only HTML5 and CSS3.

---

## 💻 How to Run Locally

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. You can also use the Live Server extension.
5. No additional setup is required.
